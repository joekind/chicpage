# 文字本来可以更好看：从写下第一句到被人看见

![pexels图片](https://images.pexels.com/photos/38667798/pexels-photo-38667798.jpeg)

排版不是装饰，是阅读节奏。

**ChicPage** 帮你把一篇 Markdown，变成适合公众号、小红书与多平台贴图的成稿。打开这份 Demo，切换主题，看看同样的文字如何换上不同气质。

> 「简单，是更高层次的精致。」


## 01、从草稿到成稿

好内容往往死在「再调一下格式」里。ChicPage 的路径很短：

1. **写** —— 用熟悉的 Markdown 起稿
2. **看** —— 右侧实时预览公众号 / 贴图效果
3. **出** —— 复制排版，或导出多比例贴图

不必在编辑器、排版工具和切图软件之间来回跳。


建议先用「默认 / 典雅 / 杂志」三个主题各扫一眼——同一份 Demo，气质完全不同。


![pexels图片](https://images.pexels.com/photos/1058651/pexels-photo-1058651.jpeg)


## 02、标题决定层级

标题不是装饰线，是呼吸。

### 二级像章节

读者扫一眼，就知道文章骨架。

#### 三级像段落提示

适合展开细节，而不抢主标题的戏。

正文里适度使用 **加粗**、*斜体*，以及行内代码 `npm run dev`。需要标注按键时，写成 <kbd>⌘</kbd> + <kbd>C</kbd> 复制排版结果。

链接保持克制：[在线体验 ChicPage](https://chicpage.quickext.com/)



## 03、列表与任务

**无序：适合观点罗列**

- 实时预览，写完即所见
- 多主题切换，一键换气质
- 贴图比例：`3:4` / `9:16` / `1:2`
- 导出图片、HTML 或 Markdown

**有序：适合步骤说明**

1. 导入本文件，或直接粘贴内容
2. 选择主题与字体
3. 预览公众号排版 / 贴图模式
4. 复制或导出，准备发布

**任务清单：适合行动项**

- [x] 写完初稿
- [x] 选好主题
- [ ] 导出小红书贴图
- [ ] 粘贴到公众号后台


## 04、引用与提示

引用适合金句、摘录、旁白：

> 排版不应该成为创作的负担。
>
> 我们希望你把注意力留给文字本身。

提示盒适合强调操作建议与风险：


贴图模式下，可用 `<!--pagebreak-->` 强制分页，让每一屏都有完整叙事。



导出前先在预览里翻一遍页——过长段落或大图可能导致切页不理想。



复制到公众号后，请勿再大幅改样式；部分平台会剥离自定义 CSS。

## 06、代码也可以好看

## 07、图片是节奏，不是堆砌

好图放在对的位置，比连放三张更有效。配图尽量短句说明：一句话交代「看到了什么」。

## 09、写作小建议

1. **一句一事**：段落不要塞两层意思
2. **标题可扫**：读者只看标题也能懂结构
3. **引用要少**：金句多了就不再是金句
4. **图文交替**：大段文字后给眼睛一个落点
5. **结尾留白**：收束即可，不必再开新战场
